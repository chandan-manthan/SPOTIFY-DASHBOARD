💬 Interview Questions & Answers
Q1. What is DAX?

DAX (Data Analysis Expressions) is a formula language used in Power BI for calculations and measures.

Q2. Difference between calculated column and measure?
Calculated Column → Stored in table
Measure → Calculated dynamically based on filters
Q3. Why did you use Power Query?

Power Query was used for:

Data cleaning
Data transformation
Removing null values
Formatting columns
Q4. What is data modeling?

Data modeling means creating relationships between tables to build efficient analytics.

Q5. Which chart is best for trend analysis?

Line charts are best for showing trends over time.

Q6. Why did you choose Spotify theme colors?

To match Spotify branding and create a visually immersive dashboard experience.

Q7. What is KPI in Power BI?

KPI (Key Performance Indicator) is a measurable value used to track performance.
